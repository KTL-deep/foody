# 🍳 Семейное Кафе (Family Cafe)

Уютное домашнее веб-приложение для планирования меню, учета рецептов с автоматическим расчетом КБЖУ (Калории, Белки, Жиры, Углеводы) и заказа блюд членами семьи.

Приложение позволяет членам семьи заказывать завтраки, обеды или ужины на определенный день, а "дежурному по кухне" — удобно просматривать заказы в реальном времени, изменять их статус и отслеживать суммарную пищевую ценность (КБЖУ баланс) на выбранный день по каждому члену семьи.

---

## ✨ Основной Функционал

### 1. Интерактивная Книга Рецептов
* **Категории**: Быстрая фильтрация по категориям:🥞 Завтрак, 🍝 Обед, 🥩 Ужин, 🥐 Выпечка, 🍰 Десерт.
* **Поиск**: Динамический "живой" поиск по названиям, ингредиентам или тексту рецептов.
* **Сортировка**: Упорядочивание блюд по времени приготовления, калорийности (по возрастанию/убыванию) и содержанию белков.
* **Просмотр рецепта**: Удобное модальное окно с подробными шагами приготовления и КБЖУ.
* **Добавление блюда**: Простая форма для добавления новых домашних блюд с расчетом КБЖУ.
* **Редактирование блюда**: Возможность отредактировать любое существующее блюдо непосредственно с карточки меню.
* **Архивация**: Возможность скрыть блюдо в архив (оно перестает отображаться в меню и становится недоступным для заказа, но сохраняется в базе данных и может быть восстановлено в любой момент через чекбокс "Показать архивные").

### 2. Заказ Блюд
* Оформление заказа непосредственно с карточки блюда.
* Выбор члена семьи (Мама, Папа, Кирилл, Маша и др.).
* Выбор даты (сегодня, завтра или любой другой день) и времени/приема пищи.
* Поле для особых пожеланий (например: "без сахара", "побольше ягод", "соус отдельно").

### 3. Интерактивная Кухня (Live View)
* Сортировка заказов по статусам: **В ожидании**, **Готовится**, **Готово**.
* Быстрые действия: кнопка "Готовить" для перевода в статус подготовки и "Готово 🎉" для завершения.
* Автоматическое обновление списка заказов каждые 30 секунд (поддержка живого экрана на планшете на кухне).

### 4. 📊 Дневной КБЖУ Баланс
* Сводная статистика пищевой ценности всех активных заказов на выбранный день.
* Автоматическая группировка по каждому члену семьи (показывает сумму калорий, белков, жиров и углеводов, которые они заказали на этот день).

### 5. ☀️/🌙 Темы Оформления
* Поддержка светлой и темной тем.
* Выбор сохраняется в локальной памяти браузера (`localStorage`).

## 🛠 Технологический Стек

* **Бэкенд**: Python 3 + FastAPI + SQLAlchemy ORM
* **База данных**: SQLite (файл `foody.db` создается автоматически в корне проекта при первом запуске)
* **Фронтенд**: Чистый HTML5 + Vanilla CSS3 (дизайн с использованием переменных CSS, CSS Grid/Flexbox и плавных переходов) + Vanilla JS (ES6+, Fetch API)

## 🚀 Быстрый запуск на локальной машине

1. **Активируйте виртуальное окружение Python** (если оно создано):
   ```bash
   .venv\Scripts\activate
   ```

2. **Установите необходимые зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите сервер разработки**:
   ```bash
   uvicorn app.main:app --reload
   ```

4. **Откройте приложение в браузере**:
   Перейдите по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)

При первом запуске база данных автоматически наполнится демонстрационными блюдами (Домашние сырники, Французский круассан, Овсяная каша с черникой, Паста Карбонара и Салат Цезарь), чтобы вы могли сразу протестировать все возможности!
