# Семейное Кафе (Family Cafe) — План Реализации

Этот проект представляет собой уютное веб-приложение для планирования домашнего меню, учета рецептов с расчетом КБЖУ и заказа блюд членами семьи (например, заказ завтрака на следующее утро).

---

## 🌟 Концепция и Дизайн
* **Стиль**: Уютный, лаконичный, минималистичный, но функциональный.
* **Цветовая палитра**: Теплые домашние тона (кремовый, нежно-бежевый, приглушенный терракотовый или оливковый, мягкий темно-серый для текста).
* **Типографика**: Красивые современные шрифты (например, Playfair Display для заголовков, Inter или Outfit для основного текста).
* **Удобство**: Полная адаптивность под мобильные телефоны (ведь заказы и рецепты чаще смотрят с телефона на кухне).

---

## 🛠 Технологический Стек
* **Бэкенд (Backend)**: Python + [FastAPI](https://fastapi.tiangolo.com/) + SQLite (для простоты и быстроты работы, база данных будет храниться локально в одном файле).
* **Фронтенд (Frontend)**: Чистый HTML5, Vanilla CSS3 (уютный кастомный дизайн с мягкими тенями, переходами и анимациями) и Vanilla JS (ES6+) для динамического обновления без перезагрузок.

---

## 🗄 Структура Базы Данных (SQLite)

### 1. Таблица Блюд (`dishes`)
Хранит рецепты, ингредиенты и КБЖУ.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | INTEGER PRIMARY KEY | Уникальный идентификатор блюда |
| `name` | TEXT | Название (например, "Сырники", "Круассан") |
| `description` | TEXT | Краткое описание или заметка |
| `recipe` | TEXT | Шаги приготовления (инструкция) |
| `category` | TEXT | Категория (Завтрак, Обед, Ужин, Десерт, Выпечка) |
| `calories` | REAL | Калории на 100г или на порцию |
| `proteins` | REAL | Белки |
| `fats` | REAL | Жиры |
| `carbs` | REAL | Углеводы |
| `prep_time` | INTEGER | Время приготовления в минутах |
| `image_url` | TEXT | Ссылка на фото блюда (или локальный путь) |
| `is_archived` | BOOLEAN | Флаг скрытия из активного меню (по умолчанию `False`) |

### 2. Таблица Заказов (`orders`)
Позволяет заказывать блюда на определенное время.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | INTEGER PRIMARY KEY | Уникальный идентификатор заказа |
| `dish_id` | INTEGER | ID заказанного блюда (внешний ключ на `dishes.id`) |
| `ordered_by` | TEXT | Кто заказал (имя члена семьи, например "Кирилл", "Маша") |
| `order_for_date` | TEXT | На какую дату/день сделан заказ (например, "2026-06-16") |
| `order_for_time` | TEXT | На какое время/прием пищи (Завтрак, Обед, Ужин, или конкретное время вроде "09:00") |
| `status` | TEXT | Статус заказа (`pending` - ждет, `accepted` - готовится, `completed` - готово, `cancelled` - отменено) |
| `note` | TEXT | Пожелание к заказу (например, "без сахара", "побольше ягод") |
| `created_at` | TEXT | Время создания заказа (timestamp) |

## 📐 Архитектура Папок Проекта

Для удобства разделим проект на бэкенд и фронтенд:
* `C:/PYTHON_PROJECTS/foody/`
  * `app/` — Код FastAPI приложения
    * `database.py` — Настройка SQLite и сессии SQLAlchemy
    * `models.py` — Описание таблиц БД (SQLAlchemy ORM)
    * `schemas.py` — Валидация Pydantic
    * `crud.py` — Логика работы с БД (создание, чтение блюд и заказов)
    * `main.py` — Инициализация FastAPI, роутеры API и раздача статики
  * `static/` — Статические файлы фронтенда
    * `css/`
      * `style.css` — Уютный кастомный стиль (дизайн-система, формы, карточки)
    * `js/`
      * `app.js` — Логика интерфейса, запросы к API (Fetch), автообновление
    * `images/` — Локальные изображения или заглушки
    * `index.html` — Главная страница (SPA с вкладками "Меню", "Заказать", "Активные заказы", "Добавить блюдо")
  * `requirements.txt` — Список зависимостей Python
  * `gemini.md` — Этот файл с планом и статусом реализации
