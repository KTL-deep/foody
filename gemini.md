# Семейное Кафе (Family Cafe) — План Реализации

Этот проект представляет собой уютное веб-приложение для планирования домашнего меню, учета рецептов с расчетом КБЖУ и заказа блюд членами семьи (например, заказ завтрака на следующее утро).

---

## 🛠 Технологический Стек
* **Бэкенд (Backend)**: Python + FastAPI + SQLite.
* **Фронтенд (Frontend)**: HTML5, Vanilla CSS3, Vanilla JS.

---

## 🗄 Структура Базы Данных (SQLite)

### 1. Таблица Блюд (`dishes`)
Хранит рецепты, ингредиенты и КБЖУ.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | INTEGER PRIMARY KEY | Уникальный идентификатор блюда |
| `name` | TEXT | Название |
| `description` | TEXT | Краткое описание |
| `recipe` | TEXT | Шаги приготовления |
| `ingredients` | TEXT | Список продуктов через запятую (для списка покупок) |
| `category` | TEXT | Категория |
| `calories` | REAL | Калории |
| `proteins` | REAL | Белки |
| `fats` | REAL | Жиры |
| `carbs` | REAL | Углеводы |
| `prep_time` | INTEGER | Время приготовления в минутах |
| `image_url` | TEXT | Путь к фото блюда |
| `is_archived` | BOOLEAN | Флаг архивации |

### 2. Таблица Пользователей (`users`)
Профили членов семьи с нормами питания.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | INTEGER PRIMARY KEY | Уникальный идентификатор |
| `name` | TEXT | Имя (уникальное) |
| `target_calories` | REAL | Цель по калориям в день |
| `target_proteins` | REAL | Цель по белкам |
| `target_fats` | REAL | Цель по жирам |
| `target_carbs` | REAL | Цель по углеводам |

### 3. Таблица Заказов (`orders`)
Позволяет заказывать блюда на определенное время.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | INTEGER PRIMARY KEY | Уникальный идентификатор заказа |
| `dish_id` | INTEGER | ID блюда |
| `user_id` | INTEGER | ID пользователя |
| `ordered_by` | TEXT | Имя (для совместимости) |
| `order_for_date` | TEXT | Дата заказа (ГГГГ-ММ-ДД) |
| `order_for_time` | TEXT | Прием пищи (Завтрак, Обед, Ужин) |
| `status` | TEXT | Статус (`pending`, `accepted`, `completed`, `cancelled`) |
| `note` | TEXT | Пожелание к заказу |
| `created_at` | TEXT | Время создания заказа |
